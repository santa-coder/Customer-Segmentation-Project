# Customer Segmentation Analysis Dashboard using Power BI

## 📌 Project Overview

The **Customer Segmentation Analysis Dashboard** is an interactive Business Intelligence solution developed using **Microsoft Power BI**. This project analyzes customer demographics, purchasing behavior, and loyalty metrics to identify meaningful customer segments that support data-driven business decisions.

The dashboard helps organizations understand their customers, improve marketing strategies, increase customer retention, and maximize business growth through actionable insights.

---

## 🎯 Project Objectives

* Analyze customer demographics and purchasing behavior.
* Identify customer segments based on spending habits and income.
* Monitor customer loyalty and satisfaction.
* Discover high-value and at-risk customer groups.
* Provide business recommendations for targeted marketing.

---
